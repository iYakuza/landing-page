# GREEN DREAM — Verse After Hours

A responsive, cyber-nocturnal microsite concept for the Green Dream project. Static HTML/CSS/JS; no framework or build step required.

## Preview locally
Open `index.html` in a browser. The hero uses the existing Webflow-hosted artwork URL. The radio controls are interactive and draggable; playback is deliberately visual-only until a licensed audio source URL is configured. Poetry titles are placeholders until connected to the published archive. CV download links to the existing Webflow asset.

## Deploy
GitHub Pages can host this static folder. In repository settings, enable Pages from the chosen branch and `/green-dream` folder, or move the files to the root for root publishing.

## Current status
Draft implementation. Do not point a custom domain or replace the live Webflow home page until visual, responsive, asset, and interaction checks are complete.
