# GREEN DREAM — Verse After Hours

A responsive, cyber-nocturnal poetry and portfolio experience built with static HTML, CSS, and JavaScript. No framework or build step is required.

## Live site

- GitHub Pages homepage: https://iyakuza.github.io/landing-page/
- Project route: https://iyakuza.github.io/landing-page/green-dream/

## Included interactions

- Responsive navigation and anchor links.
- Draggable radio panel, with minimize/expand control.
- Working station selection and previous/next controls.
- Embedded YouTube playback for the Lofi Girl and Synthwave streams; other station choices open a YouTube search rather than pretending an unverified stream is playing.
- Accessible button labels, focus styles, and reduced-motion support.
- CV profile shard linking to the public LinkedIn profile.

## Honest limitations

- Browser/network restrictions, YouTube availability, and autoplay policy can affect playback; the embed is loaded only after the visitor presses Play.
- The poetry section links to the public portfolio because individual published archive entries have not yet been supplied/connected.
- The CV shard is a concise profile summary, not a downloadable copy of the full CV.
- The visual uses the existing Webflow-hosted Green Dream hero artwork.

## Development

Open `index.html` locally in a browser. The root homepage and `/green-dream/` route use the same project stylesheet and script. GitHub Pages deployment timing depends on repository Pages settings and GitHub's publishing process.
