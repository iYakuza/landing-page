# Website structure

GitHub Pages serves this repository directly. The repository is both the website source and the canonical home for published content and media.

## Main folders

- `cv/` — professional profile and offline contact form.
- `green-dream/` — Green Dream experience, poetry index and guest notes.
- `human-archive/` — historical archive and Chamber editor.
- `transmissions/` — published Transmissions and five movements.
- `signals/` — published community Signals.
- `cms/` — owner-only publishing console.
- `content/` — canonical public JSON collections.
- `media/` — published images, audio and video.
- `shared/` and `editor-ui/` — reusable interface and editor code.
- `docs/` — current project and operating notes.
- `.github/workflows/` — GitHub validation, security and Pages deployment.

## Source of truth

- Public website, content and media: this repository, branch `main`.
- Private drafts, private draft media, favourites and sequences: `iYakuza/iyakuza-cms-private`, branch `main`.
- Future secondary backup: Google Drive. No backup automation currently runs.

There is one live site and no preview/testing deployment.
