# Mood Profile Catalogue

These are art-direction hypotheses for a flexible website theme. They are not psychological rules or claims that every person with a particular feeling wants the same visual treatment. A visitor's description and explicit selection take priority.

| Profile | Visual intention | Typography | Colour / surfaces | Layout / spacing | Motion |
|---|---|---|---|---|---|
| Calm | Quiet, grounded, spacious | Neutral sans-serif | Muted greens, soft edges | Airy, generous breathing room | Gentle |
| Sad | Reflective, subdued, intimate | Editorial serif | Cool, low-saturation tones | Quiet hierarchy, less visual noise | Slow/subtle |
| Anxious | Stable, predictable, low-stimulation | Familiar sans-serif | Soft contrast, restrained accents | Spacious, consistent, uncluttered | Reduced |
| Happy | Playful, warm, youthful | Comic Neue body and display | Brighter warm palette, rounded surfaces | Expressive but readable | Playful, never flashing |
| Angry | Strong, direct, controlled | Metal Mania display headings; neutral sans body | Deep red/charcoal, sharper geometry | Bold hierarchy, strong alignment | Firm/static; no aggressive animation |
| Romantic | Dreamy, tender, intimate | Great Vibes display headings; readable serif body | Plum, rose and warm muted tones | Softer rhythm, open spacing | Gentle |
| Tired | Restful, easy to scan | Familiar sans body; restrained serif headings | Muted cool neutrals | Comfortable line-height, low density | Reduced |
| Focused | Clear, structured, distraction-light | Neutral sans-serif | Restrained cool palette | Strong grid, clear grouping, minimal decoration | Minimal |
| Hopeful | Open, fresh, uplifting | Humanist sans-serif | Fresh greens and light accents | Open composition, organic details | Gentle |
| Reflective fallback | Thoughtful, balanced | Editorial serif | Original restrained palette | Balanced density | Gentle |

## Typography rationale

- **Happy / Comic Neue:** friendly, informal, rounded letterforms. Use for short-to-medium text only if the visitor finds it comfortable; keep line length and size generous.
- **Romantic / Great Vibes:** expressive script is suitable for display headings and short labels, not paragraphs, navigation or form controls.
- **Angry / Metal Mania:** genre-coded display lettering gives the theme a heavier visual identity. Keep it to headings and short accents so the page remains usable.
- **Sad / Reflective / Tired:** serif display typography can create an editorial, contemplative tone. Body copy remains readable at normal sizes.
- **Anxious / Focused / Calm:** familiar sans-serif typography reduces stylistic complexity and supports scanning.

## Palette guardrails

- Keep body text contrast at WCAG AA where practical (4.5:1 for normal text; 3:1 for large text).
- Do not reduce contrast just to make a mood feel muted.
- Accent colours should not replace clear focus indicators.
- Keep link states and interactive states distinguishable without relying on hue alone.

## Future profile ideas

Possible later profiles: Curious, Nostalgic, Melancholic, Playful, Minimal, Energetic. Add them only when each has a genuinely distinct design system rather than a renamed colour palette.
