FIRST-TIME SETUP

ACCESS IS GRANTED MANUALLY.

  1. In Supabase → Authentication → Users, create an email/password user for yourself and copy its UUID.
  2. Open the SQL Editor and run this, replacing the placeholder with that UUID:
    insert into public.vha_cms_admins (user_id) values ('REPLACE-WITH-YOUR-USER-UUID') on conflict (user_id) do nothing;
  3. Return here and sign in with that account. Only explicitly listed users can publish or edit posts.

The database owner performs the one-time access grant. The website cannot grant itself CMS access.
