GREEN DREAM // BACKUP TOOL

Privacy Policy

Last updated: 13 November 2026

Green Dream Backup is a personal tool used by the owner of the Green Dream / Verse After Hours website to create and recover backups in that owner's Google Drive. It is not a public backup service and is not intended for use by other people.

Information and files handled

When a backup or recovery workflow is run, the tool may handle:

  • A Google OAuth authorisation token, used by rclone to access Google Drive for the backup operation.
  • An encrypted website content backup. Depending on the workflow version, its contents can include the website's public database schema and data, Supabase Storage object metadata and files, published WordPress content and associated media, and the website repository and its assets.
  • A small, unencrypted completion manifest containing a backup identifier, creation time, archive filename, file size, checksums, and encryption-format information. It does not contain the backup archive's content.

How information is used

The Google authorisation token is used only to let the backup workflow create, list, read, and download backup files in the owner's Google Drive. Backup content is packaged and encrypted with GPG using AES-256 before the archive is uploaded. The encryption passphrase is supplied separately to the workflow and is not included in the Drive manifest.

The workflow uses GitHub Actions to run the backup and recovery jobs. Temporary working files are removed by the workflow's cleanup steps. A portable, read-only recovery website may also be stored as a GitHub Actions artifact for up to seven days.

Where information is stored

Encrypted backup archives and their completion manifests are stored in a dedicated folder in the owner's Google Drive. The owner controls that Drive account and can manage or delete those files there. GitHub processes workflow code, configuration, and temporary backup material while a workflow runs. GitHub Actions secrets are used to supply credentials to the workflow.

Sharing

This personal tool does not sell personal information, use Drive backup content for advertising, or intentionally share backup contents with other people. Google provides the Drive storage and OAuth services, and GitHub provides the repository and Actions infrastructure; their services are subject to their own privacy terms.

Retention and deletion

Backup files remain in the owner's Google Drive until the owner deletes them. The backup workflow does not automatically delete or rotate existing Drive backups. The owner can revoke the app's Google access in their Google Account security settings and can remove the relevant GitHub Actions secret to stop future workflow access. GitHub Actions recovery-site artifacts are configured for seven-day retention.

Security

Backup archives are encrypted before upload using GPG symmetric AES-256 encryption. The encryption passphrase is kept separately from the archive and should be stored securely by the owner. The workflow verifies archive checksums during upload and recovery. No method of storage or transmission is completely risk-free, and the owner is responsible for protecting account credentials and the encryption passphrase.

Changes to this policy
