Privacy Notice

Last updated: 22 November 2026

The automated Green Dream backup and recovery tooling described by the previous version of this page is no longer active in the current website migration candidate. Its GitHub Actions workflows and related Supabase / Cloudflare integration code have been withdrawn from the active project.

Existing archives

These repository changes do not access, delete, move, or modify any existing backup files in the owner's Google Drive. Those files remain under the owner's control and can be managed directly in that Google Drive account. No new automated backup or recovery job is being run by the current website project.

Current website architecture

The migration candidate uses GitHub Pages for the public website, GitHub repositories for published content and private CMS data, and the GitHub API for authenticated CMS operations. The previous Supabase Functions and Cloudflare recovery-hosting code are not part of the active candidate.

Future changes

A replacement backup and recovery process is deferred until after the production migration. This notice will be revised before any new service is introduced. Removing old integration code from the repository does not decommission external accounts or delete data held by those providers.
