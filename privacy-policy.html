Privacy Notice

Last updated: 22 November 2026

Website and content

This is a public, static website hosted through GitHub Pages. Published writing, conversations, images, audio and video are stored in the website's GitHub repository and are publicly accessible by design.

CMS access

Owner-only publishing actions use the GitHub API. The owner supplies a GitHub token for the editing session. The website does not use a separate hosted database or visitor account system. Unpublished drafts and private draft media are stored in the private GitHub companion repository.

Visitor data

The website does not run a visitor analytics tracker. The CV contact form and public Signal submission form are currently disabled; those forms do not send or store submissions.

Embedded media

Some published entries may embed or link to media hosted by third-party services, such as YouTube, Spotify, SoundCloud, Vimeo, Dailymotion or Loom. When a visitor opens or plays that content, the provider may receive the usual connection information under its own privacy policy.

Backups

Automated backup and recovery are not currently enabled. Existing personal archive files in Google Drive remain under the owner's control. A GitHub-based backup and recovery process may be added later.
